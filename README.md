# Balloon 🎈

A tiny crayon-style game: hold on to your balloons and float up past branches, birds, thunderclouds and meteors, all the way to the moon.

- **Play:** open `index.html`, or the GitHub Pages link once Pages is on
- **Controls:** drag left/right anywhere on the screen; on a computer use the arrow keys, P to pause
- **Score:** height plus daring points. Brush past an obstacle without touching it for +5, and keep chaining close shaves for combos (x2, x3…). Reaching the moon gives +300.
- **Ghost:** your best run flies along with you as a see-through ghost.
- **Daily:** the same course for everyone each day, so you can compare scores and share them.
- **Change the art:** replace the images in `src/sprites/`, then run `python3 src/build.py` to rebuild `index.html`
