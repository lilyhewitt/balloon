# Balloon 🎈

A tiny crayon-style game: hold on to your balloons and float up past branches, birds, thunderclouds and meteors.

- **Play:** open `index.html`, or the GitHub Pages link once Pages is on
- **Controls:** drag left/right anywhere on the screen; on a computer use the arrow keys, P to pause
- **Change the art:** replace the images in `src/sprites/`, then run `python3 src/build.py` to rebuild `index.html`
